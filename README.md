## ✨ Features

- **🏛️ Interactive 3D Flacon Showroom**: Real-time 3D crystal flacon viewer with dynamic lighting, liquid rendering, and 360° orbit powered by `@react-three/fiber` & `@react-three/drei`.
- **🧪 3D Fractional Distillation Alembic**: Interactive 3D copper alembic still exploring Top, Heart, and Base botanical extraction nodes.
- **🔺 3D Olfactory Notes Pyramid**: Tiered pyramid visualization of fragile top volatiles, heart florals, and deep resinous sillage.
- **✨ Bespoke Client Concierge**: AI scent discovery matchmaking, personalized consultations, and dynamic shopping bag management.
- **📜 Automated PDF Invoicing**: Client certificates of authenticity and executive billing invoices generated with `jspdf` & `jspdf-autotable`.
- **🔒 Executive Staff Command Portal**: Dedicated management interface for orders, products, client accounts, and revenue analytics.

## 🛠️ Technology Stack

- **Framework**: [Next.js 14](https://nextjs.org/) (App Router, Server Components & Dynamic Client Splitting)
- **3D Graphics**: [Three.js](https://threejs.org/) & [React Three Fiber](https://docs.pmnd.rs/react-three-fiber)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (Custom Obsidian & Gold Luxury Design System)
- **Typography**: Cinzel, Playfair Display & Plus Jakarta Sans
- **Animations**: [Framer Motion](https://www.framer.com/motion/) & [GSAP](https://greensock.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17+ or higher
- npm / yarn / pnpm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/aura-sovereign.git

# 2. Navigate to project root
cd aura-sovereign

# 3. Install dependencies
npm install

# 4. Launch the luxury development showroom
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
